the declaration
// types & predicates
const Node = s.type("Node");
const Atom = s.type("Atom", Node);
const Carbon = s.type("Carbon", Atom);
const Nitrogen = s.type("Nitrogen", Atom);
const Hydrogen = s.type("Hydrogen", Atom);
const SingleBond = s.predicate("SingleBond", [Node, Node]);
const DoubleBond = s.predicate("DoubleBond", [Node, Node]);

// one rule per atom subtype
s.forall({ a: Carbon }, ({ a }) => {
  s.circle({ center: [pos(a).x, pos(a).y], r: 24, fill: "#fff", stroke: "#111827" });
});

// bonds are predicates, not ad-hoc edges
s.forallWhere({ a: Node, b: Node }, ({ a, b }) => SingleBond.test(a, b), ({ a, b }) => {
  s.line({ start: center(a), end: center(b), stroke: "#94a3b8", strokeWidth: 9 });
});

아직 없는 Penrose 기능

  • Image, Ellipse, Equation 도형 — 현재 Circle / Line / Rect / Text만 지원
  • collect ... into, Group, CSS filter: blur()
  • 스타일에서의 override, none(), 색상 함수 rgba()의 선언형 문법
  • where x has label, AutoLabel, Label 같은 Trio 문법 설탕
  • 상대 레이어(above/below) — 현재는 숫자 layer
  • .domain / .style / .substance 파일 파서

이 예제는 그중 의미 구조와 기하를 Kite API로 직접 옮긴 것입니다. Trio 텍스트 파서나 Group/Image 도형이 필요하면 엔진에 추가할 수 있습니다.
