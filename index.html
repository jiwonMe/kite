Declarative diagrams that pull themselves into shape.

Kite는 Penrose의 Trio(도메인 · 서브스턴스 · 스타일) 철학을 단일 ES 모듈로 재설계한 다이어그램 엔진입니다. ensure는 하드 제약, 마우스는 유한 컴플라이언스 소프트 제약으로 취급되어 XPBD 솔버가 매 프레임 마우스를 제약 다양체 위로 정사영합니다.

Two ways to get dragged.

상수를 자유 변수로 승격하는 Auto-Slacking, 그리고 도형을 함께 끌고 가는 하드 등식. 둘 다 별도 콜백 없이 선언만으로 동작합니다.

Auto-Slacking

derived coord + drag

c2.center = [c1.x + 80, c1.y]. 어느 원을 잡아도 80px 간격이 유지됩니다.

Euler diagram

subtyping · contains · disjoint

다중 상속 타입과 비트마스크 매칭. 내부 집합을 끌어도 A 밖으로 빠져나가지 않습니다.

Append, don’t rebuild.

런타임에 새 Substance 인스턴스를 추가해도 기존 변수는 그대로입니다. 새 규칙 일치만 실행되어 바이트코드 테이프 끝에 증분 추가됩니다.

Six more manifolds.

삼각함수, 상자 벽, 링크 기구, 직각, 렌즈, 외부 입력. 같은 ensure / ops로 선언하고, 점을 잡아 끌면 솔버가 그 다양체 위로 되돌립니다.

Sine wave

sin · inequalities

y = 52·sin(x/34). 곡선 밖으로 끌어도 파형 위로 돌아옵니다. 좌우 끝은 하드 부등식입니다.

Inside the box

four inequalities

네 개의 하드 부등식이 벽을 만듭니다. 모서리로 끌면 벽을 따라 미끄러지고, 상자 밖으로는 나가지 않습니다.

Three-bar linkage

pinned hinge · length

검은 힌지는 고정입니다. 1·2·3 관절을 끌면 막대 길이 78px이 유지된 채 팔이 접힙니다.

Right angle

ops.dot == 0

두 막대의 내적이 0이고 길이는 110입니다. 한쪽 끝을 돌리면 다른 쪽이 직각을 유지합니다.

Lens

overlapping · contains

두 큰 원은 36px 이상 겹쳐야 하고, 빨간 점은 그 교집합 안에만 머뭅니다.

Bead on a segment

setInput

구슬은 x축 선분 위에만 있습니다. 길이를 줄이면 구슬이 구간 안으로 밀립니다.

One file. Four ideas.

Template JIT · flat tape autodiff · inline Blob worker · fine-grained SVG patch. 외부 런타임도, 헤더 설정도 필요 없습니다.

example.jsES2022 · 0 dependencies
import { scene, $, ensure, ops } from "./kite.js";

const s = scene("#stage", { width: 600, height: 600 });

const orbit = s.circle({ center: [0, 0], r: 150, fill: "none" });
const planet = s.circle({ center: [150, 0], r: 18, drag: true });

// A hard equality: the planet is projected onto the circle every frame.
ensure`${ops.dist(planet.center, orbit.center)} == ${orbit.r}`;

// Mouse pull is a finite-compliance soft constraint. No dragConstraint callback.
await s.mount();
